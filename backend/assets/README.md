# Projection asset

Place the authorized `CIOmode_1982_2017.mat` file in this directory, or set `CIOPROJ_MAT` to its absolute path.

This file supplies the historical projection constants and reference EOF fields. It is excluded from Git. Do not replace it with a newly estimated EOF while reusing the existing forecasts: that changes the predictor definition.

See [Data setup](../../docs/data-setup.md) for the remaining assets.
